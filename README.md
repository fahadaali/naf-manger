# NAF Law - نظام إدارة المكتب القانوني

نظام شامل لإدارة المكاتب القانونية مع ميزات متقدمة للعملاء والقضايا والتحليلات.

## الميزات الرئيسية

- 📊 لوحة تحكم شاملة مع إحصائيات في الوقت الفعلي
- 👥 إدارة العملاء والعملاء المحتملين
- ⚖️ إدارة القضايا والأعمال القانونية
- 📈 تحليلات متقدمة وتقارير مخصصة
- 🤖 مساعد ذكي مدعوم بـ Gemini AI
- 💼 إدارة المسوّقين والعمولات
- 📧 نظام البريد الإلكتروني والاجتماعات
- 🎨 واجهة مستخدم عصرية ومتجاوبة

## التشغيل

### الواجهة الأمامية (Frontend)

```bash
# تثبيت المكتبات
npm install

# تشغيل خادم التطوير
npm run dev
```

### خادم البريد الإلكتروني (Email Server)

```bash
# الانتقال إلى مجلد الخادم
cd server

# تثبيت المكتبات
npm install

# إنشاء ملف البيئة
cp .env.example .env

# تحرير ملف .env وإضافة بيانات البريد الإلكتروني
# EMAIL_USER=your-email@yourdomain.com
# EMAIL_PASSWORD=your-app-password
# EMAIL_FROM=noreply@naflaw.com

# تشغيل الخادم
npm start
```

## إعداد البريد الإلكتروني

1. **Gmail:**
   - الخادم: `smtp.gmail.com`
   - المنفذ: `587`
   - الأمان: STARTTLS
   - قم بإنشاء App Password من إعدادات الحساب

2. **Outlook/Hotmail:**
   - الخادم: `smtp-mail.outlook.com`
   - المنفذ: `587`
   - الأمان: STARTTLS

3. **Hostinger:**
   - الخادم: `smtp.hostinger.com`
   - المنفذ: `587`
   - الأمان: STARTTLS

## التقنيات المستخدمة

- **Frontend:** React + TypeScript + Tailwind CSS
- **Backend:** Node.js + Express + Nodemailer
- **AI:** Google Gemini AI
- **Charts:** Chart.js + React Chart.js 2
- **Icons:** Heroicons + Lucide React
- **التخزين:** Local Storage (للنموذج التجريبي)
